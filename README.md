🎮 Tic-Tac-Toe Game

An interactive two-player Tic-Tac-Toe game developed using HTML, CSS and JavaScript. Players take turns marking X and O on a 3×3 grid, with automatic winner and draw detection.

🖥️ Project Overview

This project provides a simple and engaging gaming experience with an interactive interface, turn-based gameplay and instant result announcements.

🛠️ Technologies Used

HTML5 – Structure of the game.

CSS3 – Styling and user interface design.

JavaScript – Game logic, player turns and winner detection.

✨ Key Features

🎯 Interactive 3×3 game board.

👥 Two-player gameplay (X and O).

🔄 Automatic player turn switching.

🏆 Winning pattern detection.

🤝 Draw detection when all cells are filled without a winner.

🔁 New Game option to start a fresh match.

♻️ Reset button to restart the current game.

⚙️ How It Works

Two players participate in the game.

Player O starts the game, followed by Player X.

Players take turns selecting empty cells.

The application checks predefined winning combinations after every move.

If a player completes a winning combination, the winner is announced.

If all nine cells are filled without a winner, the game declares a draw.

Players can use the New Game or Reset button to play again.
